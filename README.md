# Border Skip Hire

Website for Border Skip Hire Ltd, a skip hire company covering South Armagh and South Down, Northern Ireland.

Built with React + Vite. Deploys to GitHub Pages via `.github/workflows/deploy.yml` on push to `main`.

```
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

Business details (phone numbers, skip sizes, towns covered, waste rules) live in `src/data.jsx`.
